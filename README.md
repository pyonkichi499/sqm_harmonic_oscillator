# 1次元調和振動子の確率過程量子化 (Parisi-Wu)

## 概要

このリポジトリは、Parisi-Wu の確率過程量子化（Stochastic Quantization Method: SQM）を用いて、1次元調和振動子モデルを数値的に解くことを目的としたプロジェクトです。
数値シミュレーションの実装練習と、その結果を解析解と比較検証することを目指します。

## 背景と目的

### 確率過程量子化 (Parisi-Wu)

場の量子論や統計力学における分配関数や物理量の期待値は、経路積分を用いて定義されます。Parisi-Wu の手法では、この経路積分を直接計算する代わりに、系に対応する確率的な動力学方程式（ランジュバン方程式）を導入し、その架空時間発展における平衡状態として元の理論の期待値を求めます。

### 本プロジェクトの目的

* 1次元調和振動子に対するランジュバン方程式を導出し、離散化する。
* 離散化されたランジュバン方程式を数値的に解くアルゴリズムを実装する。
* シミュレーションによって得られた物理量（例: $\langle x^2 \rangle$）を、量子力学の解析解と比較し、手法の妥当性を検証する。
* 数値計算におけるパラメータ（離散化ステップ、シミュレーション時間など）の影響を調査し、理解を深める。

## 対象モデル: 1次元量子調和振動子

* ハミルトニアン:
    $$ \hat{H} = -\frac{\hbar^2}{2m} \frac{d^2}{dx^2} + \frac{1}{2} m \omega^2 x^2 $$
* ユークリッド作用 (虚時間経路積分):
    $$ S_E[x(\tau)] = \int_0^\beta d\tau \left[ \frac{1}{2}m \left(\frac{dx}{d\tau}\right)^2 + \frac{1}{2}m\omega^2 x(\tau)^2 \right] $$
    ここで $\beta = 1/(k_B T)$。基底状態を考える場合は $\beta \to \infty$ の極限を扱います。
* 解析解 (基底状態):
    * エネルギー: $E_0 = \frac{1}{2}\hbar\omega$
    * 期待値: $\langle x^2 \rangle_0 = \frac{\hbar}{2m\omega}$
    (簡単のため、シミュレーションでは $\hbar=1, m=1, \omega=1$ とすることが多いです)
